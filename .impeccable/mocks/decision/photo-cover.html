Geoffrey Adam Tomagan studies computer science at the University of the Philippines Tacloban. He has built four projects so far, and each one is a different kind of software.

SkolarTrack is a full-stack web app for scholarship applications. AntiDoomScroll is a Chrome extension. Pathfinder-8 is a browser game with an A* solver.

He works mainly in JavaScript and Java, and is looking for freelance work and junior developer roles.

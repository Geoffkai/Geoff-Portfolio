SkolarTrack

Full-stack web app

A scholarship aggregator and application tracker for Filipino students. It gathers CHED, DOST, foundation and local government scholarships in one searchable list, and each student tracks applications from Interested to Result.

Stack
React, Vite, Node.js, Express, PostgreSQL
Access
JWT logins with bcrypt, separate student and admin roles
Year
2026, in active development

AntiDoomScroll

Chrome extension

A Chrome extension that interrupts endless scrolling. Pick the sites and a time limit. When the time is up, a full-page prompt asks you to take a break, snooze for a minute, or close it.

Stack
JavaScript, Chrome extension APIs, Manifest V3
Works on
Facebook, Instagram, TikTok and YouTube
Year

Pathfinder-8

Puzzle game with A* solver

An 8-puzzle you can play in the browser. If you get stuck, the built-in solver finds the shortest solution with A* search and plays it back, reporting how many states it explored.

Stack
JavaScript, HTML and CSS
Solver
A* search, Manhattan distance heuristic, binary min-heap
Year
2025

Can You Pass SOPP?

Java quiz game

A quiz game for the Survey of Programming Paradigms course. Pick a classmate character, choose theory or programming questions, and climb five levels from procedural and functional to object-oriented and event-driven programming. Built with a classmate.

Stack
Java 21, Swing, Maven, JSON question banks
Game
Five levels, two question categories, score records and sound
Year
